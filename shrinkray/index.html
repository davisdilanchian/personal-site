ShrinkRay

OPERATIONAL

Squeeze images under a size limit, entirely in the browser. Nothing is uploaded.

▸ Open ShrinkRay ▸ View on GitHub
EXHIBIT — SHRINKRAY
▌ Overview

Drag in a batch of images, set a maximum file size, and hit Compress. The default target is 7.99 MB, Discord's free-tier limit, on a slider from 0.2 to 25 MB. Files already under the limit pass through untouched, so nothing is re-encoded for no reason.

JPEG, PNG and WebP decode natively. Camera RAW files (CR2, CR3, NEF, ARW, DNG, RAF and more) work by extracting the full-size JPEG preview the camera embeds in the file. Everything runs client-side: no server, no upload, no account.

▌ Known Capabilities
  • Batch compression
  • Camera RAW previews
  • Adjustable size target
  • Client-side only
